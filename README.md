# SnapNet — Freelance Hiring Platform

A static HTML/CSS/JS prototype for a freelance hiring platform that connects clients with skilled professionals in their region.

## Pages

- `index.html` — Landing page (hero, navigation, footer)
- `hire-me.html` — Browse and hire talent profiles
- `how-it-works.html` — How the platform works
- `sign-up.html` — Create an account
- `profile.html` — Personal profile space (placeholder)

## How to open

Just double-click `index.html` in a browser, or serve the folder locally:

```console
python -m http.server 8000
```

Then visit http://localhost:8000.

> Profile photos reference local placeholder images in `images/placeholder.svg`. Replace them with real photos as the project develops.
